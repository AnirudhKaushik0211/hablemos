# Hablemos: data sources and licensing

## Summary

All content in `data/` is original. No dictionary, textbook, app, website, corpus or open dataset was copied, scraped, translated or adapted. No open dataset is used, so there is no third-party licence or attribution to honour. The content is released with the rest of the project under the MIT licence (see `LICENSE`).

The basis for the Spanish is "authored from standard grammar": the author wrote every word, gloss, example sentence, phrase, dialogue and note from general knowledge of standard Spanish grammar and common usage, then checked the result with programmatic tests and a separate review. Grammar rules (gender, plural formation, verb endings, stem changes, apocope, contractions) are facts about the language, not copyrightable text, and are implemented as code in `js/`.

## What is in each data file

| File | Content | How it was made |
|---|---|---|
| `data/words.js` | About 1,000 words with part of speech, gender, tier (A1, A2, B1), category, an example sentence with English, and optional notes and regional variants | Written by hand. Tiers are the author's own judgement of how early a learner meets the word, not a published frequency list. |
| `data/phrases.js` | About 300 phrases in eight situations, with English, tier, optional notes and regional variants | Written by hand as ordinary traveller and everyday phrases. |
| `data/verbs.js` | Verb list with irregularity data (stem changes, irregular stems, full tables for the most irregular verbs) | Written by hand. The conjugation engine (`js/conj.js`) applies the rules; only exceptions are stored. |
| `data/falsefriends.js` | Words that look like an English word but mean something else | Written by hand. |
| `data/idioms.js` | Idioms with a literal translation, the meaning and an example | Written by hand. Idioms are common expressions; the glosses and examples are original. |
| `data/pronunciation.js` | Pronunciation and stress tips with plain-English respellings | Written by hand. |
| `data/scenarios.js` | Four branching dialogues (café, directions, hotel, pharmacy) | Written by hand. |
| `data/entext.js` | English-side function words, irregular English forms, number words, contractions, fixed fragments | Written by hand from standard English. |
| `data/why.js` | Plain-language grammar explanations (no longer shown in the UI after the offline translator was retired) | Written by hand. |

## Checks applied to the data

- `test/data.test.cjs` checks required fields, valid parts of speech, genders, tiers and categories, unique ids and keys, Unicode NFC, no stray whitespace, that every example sentence contains a form of its word, that every verb word has a conjugation, the minimum counts, and that every scenario path ends.
- `test/conj.test.cjs` compares the conjugation engine with reference tables for 36 verbs across the present, preterite, imperfect, future and command forms (including negative commands). The reference tables were written separately from the engine, from standard grammar, and are not generated by it.
- `test/agreement.test.cjs` checks plural formation, adjective agreement, apocope, articles (including `el agua`), contractions and number words.
- An independent reviewer samples the authored data (words, phrases, idioms, false friends, scenario lines) for Spanish accuracy as a separate step; the gate is 0 errors in the sample and never above 2%. Online translations are third-party output and are not sampled.

## Regional variants

Where Spain and Latin America differ in common vocabulary (for example `coche` and `carro`, `ordenador` and `computadora`, `billete` and `boleto`), the entry carries a `var` field and the Spain/Latin America setting chooses the form. The Latin America form is a general choice and some countries use another word. Voseo and other regional grammar are out of scope.

## Limits

- The Spanish was not written or certified by a native-speaker editor. Treat it as a careful learner resource and report mistakes through the project's issue tracker.
- Free-text translation is online only (MyMemory, third-party, consent required; see `README.md`). Nothing in `data/` is machine generated, and the app never generates Spanish when the service is unavailable.
- The optional online translation uses a third-party service chosen by the user at the moment of use. Its output is not part of this dataset.
